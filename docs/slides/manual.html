커밋 = 사진 한 장

어느 순간의 파일 전체 상태를 찍어 둔다. 무엇을 바꿨는지 메모가 함께 붙는다.

SHA = 사진의 지문

사진마다 붙는 고유번호다. 내용이 한 글자만 달라도 번호가 바뀐다. 보통 앞 7자리로 줄여 쓴다.

프레임워크는 지문을 대조한다

검사한 것과 반영할 것이 같은 SHA인지 확인한다. 다르면 멈춘다.

그림 속 번호는 예시다. 실제 SHA는 40자리이고, 화면에는 앞 7자리가 보인다

06 · 하지 말 것

45 / 47

이것만은 하지 않는다

✕

비밀 값 붙여 넣기

토큰·비밀번호는 Issue·댓글·채팅에 쓰지 않는다.

대신 → Settings › Secrets에만 넣는다

✕

확인 없이 Merge

검사 결과와 바뀐 파일을 보기 전에는 누르지 않는다.

대신 → 35쪽의 네 가지를 본다

✕

프레임워크 파일 수정

.github/, src/self-improvement/, policy/는 안전장치다.

대신 → 도우미에게 맡긴다

✕

앱 코드 직접 고치기

직접 고치면 검사와 기록이 남지 않는다.

대신 → 요구로 쓴다

✕

낯선 사람의 승인

공개 저장소에서는 모르는 계정의 PLAN-승인도 구현을 시작시킨다.

대신 → 결과 PR을 닫고 도우미에게 알린다

✕

요구 하나에 여러 변경

한 번에 바꿀 수 있는 파일은 8개까지다.

대신 → Issue를 나눠 쓴다

실수했다면 숨기지 말고 도우미에게 바로 알린다. 비밀 값이 노출됐다면 즉시 새 값으로 바꾼다
